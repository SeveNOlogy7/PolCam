# 0001 — 能力档位决定"设备写入类"控件的可用性

状态：accepted（2026-10-01）

PolCam 的交付对象是自己从 GitHub Release 下载安装包的外部用户，他们大多没有大恒偏振相机，
也没有本软件产出的 RAW 文件。应用据此按四态决定界面可用性：`NO_DRIVER`（`gxipy` 导入失败，
`camera_module.gx is None`）、`IDLE`（驱动在、还没连接）、`NO_DEVICE`（连续两次枚举到 0 台）、
`CONNECTED`。只有**设备写入类**控件（单帧采集、连续采集、曝光/增益及其单次自动、单次白平衡）
在非 `CONNECTED` 时禁用，并在 tooltip 与引导页写明原因；**"连接相机"始终可点**，用户插好线要能
直接重试；读取文件、显示模式、软件缩放、保存、设置对话框一律不受约束。
**缩放/框选/复原不在设备写入集合内**：`image_toolbar_controller` 本来就先看 `is_connected()`，
没连接时它们做的是软件缩放——那是对读文件的人也成立的能力，锁掉等于为了术语整齐砍掉一条活路。
档位由事件驱动重算（启动、枚举变化、连接/断开、错误），
且**连续两次枚举为 0 才降到 `NO_DEVICE`**——枚举本身有瞬态失败，不防抖就会闪。原因文案不放状态栏：
实测游标读数单行就要 915px，而窗口最小宽 853px，那里已经在被截断。

## 备选方案

- **只看 `is_connected()` 一档**：让 `NO_DRIVER` 与 `NO_DEVICE` 长得一样，而用户的修法完全不同
  （装驱动 vs 查 USB/供电），等于把问题推给日志。
- **只做三档，把"驱动在、有设备、还没连接"归进 `NO_DEVICE`**：那是这台机器每次启动的默认态，
  归进去就等于一开机告诉用户"没检测到相机设备，检查 USB"，而点一下连接就能连上。所以加了
  `IDLE`，文案是通用的"尚未连接相机，点连接相机"。同理**启动时不主动枚举**（那次调用有耗时也
  会抖），没探过就停 `IDLE`，不谎报。
- **再加"设备被占用"一档**：真机测过——被别的程序占用的设备 `access_status` 仍是 0，只有 open 时
  才报 `InvalidAccess{-8}`，所以它只能试了才知道，预判不出来。
- **沿用 mono 相机隐藏白平衡面板的先例整组隐藏**：确实不留"能点但无效"的控件，但设备面板忽隐忽现
  会让侧栏宽度跳动。
- **不禁用、点击时才解释**：与禁用互斥——Qt 里 `setEnabled(False)` 的控件不接鼠标事件，点了根本
  没有事件可拦。
- **只改 README / 状态栏常驻一行**：前者装完就没人读，错仍在第一现场发生；后者挤掉已有读数。

## 后果

- 多了一个能力状态机的所有者，和一条 UI 依赖：**今后每个新控件都要声明自己是否属于设备写入类**。
- 验收在 CI 里用显式 `gx = None` 造档（`tests/test_camera_module.py` 钉住
  `gx is None → device_manager is None → sdk_available False` 这条唯一的降级链，
  `tests/test_gui.py` 再钉住窗口据此落在 `NO_DRIVER`）。注意 `tests/conftest.py` 在 gxipy
  缺失时把整包换成 MagicMock，所以流水线自己不会自然走到"真没驱动"。
- 真实缺驱动的环境跑过两次：**Windows 上把 SDK 环境变量剥掉**使 `import gxipy` 抛错
  （2026-09-29 端到端复核），以及 **Linux 容器**里 `python:3.12-slim` 上 gxipy 自己报
  `Cannot find libgxiapi.so.`（2026-10-01）——应用能起，档位是 `NO_DRIVER`，
  采集/连续/曝光/增益/单次白平衡全禁用且 tooltip 与引导页都指向驱动，点「连接相机」
  给出一次明确对话框而不是崩溃。**仍未跑过**：一台真的没装 Galaxy SDK 的 Windows 机器，
  以及打包后的 exe 在那种机器上的表现（本机装了 SDK，造不出这个环境）。
- 同时决定**不打包样例数据**，因此无相机用户的首次出图路径以诚实说明收尾，不以结果收尾；
  README 里"没装驱动仍可读取已保存的原始图像做处理"那句要改成实话（它假设下载者已经有 RAW 文件）。

术语见 `CONTEXT.md`：能力档位、设备写入类控件、首次出图路径、能力清单。
